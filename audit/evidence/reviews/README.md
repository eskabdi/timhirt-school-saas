# Reviewer verdicts

Each `wp00-r3-*.md` file holds a reviewer's verdict as returned. Lines that begin with `→` (for example "→ **fixed after this verdict**") are **implementer annotations**, not reviewer text (gatekeeper G3-2). From WP-01 on, verdicts are stored unannotated, and the implementer's response goes in `audit/FIXES_VERIFIED_R6.md`.
